# 0003 상태 레일 폐기

상태: 채택(잠정)   날짜: 2026-10-09   관련: D10, D19, D21, brief §6.16 K3, README §7.3

## 맥락

현재 작업 행(`app/src/lib/components/jobs/JobItem.svelte:78-93,190-197`)은 왼쪽에 3px 색 레일을 두어 상태(받는 중·일시정지·실패·완료)를 나타낸다. `A-DRIFT-K3`은 이를 "색+아이콘+문구 세 겹, 왼쪽 3px 레일"로 적고 **유지할 것**으로 분류했고, brief §6.16도 K3을 유지 항목에 넣었다(레일을 정수값 3px로).

그러나 실패 행을 실제로 보면 빨간 레일 + 빨간 테두리 + 빨간 막대 + 빨간 아이콘 + 빨간 글자로 **5겹**이다(`A-VIS-20`). B 후보는 레일을 유지해 4겹이었고(`J-F-B2`), A 후보는 레일 없이 막대 색·아이콘 모양·글자 세 겹으로 상태를 전했다. 판정은 A의 세 겹이 충분하고 레일이 소음이라고 봤다(judgment §2.2 "B에서 버릴 것").

이 ADR은 brief §6.16의 유지 항목을 번복하는 것이므로 사유를 기록한다.

## 결정

작업 행의 **상태 레일을 두지 않는다.** 상태는 세 겹으로 전한다:

| 겹 | 수단 | 토큰·모양 |
|---|---|---|
| 색 | 진행 막대 채움 | 받는 중 `--accent`, 일시정지 `--border-strong`, 실패 `--danger`, 완료 막대 없음 |
| 모양 | 아이콘 | 실패 `circle-x`(`--danger-ink`), 경고 `triangle-alert`(`--warning-ink`), 완료 `check`(`--fg-muted`), 연결 대기 막대 줄무늬(forced-colors에서는 dashed 테두리) |
| 글자 | 상태 줄 | "받는 중 · 2.3GB / 4.0GB", "일시정지됨", "저장 공간이 부족해요 · …", "완료" |

실패 행은 막대·아이콘·글자 외에 테두리·면 색을 바꾸지 않는다(빨강은 두 곳: 막대 채움과 아이콘·상태 글자). 색각 이상·forced-colors에서는 모양(아이콘)과 글자가 남는다(WCAG 1.4.1).

## 결과

- `patterns.md` 작업 행 절이 세 겹 표를 소유한다. `components.md` Row는 왼쪽 레일 슬롯을 갖지 않는다.
- `A-DRIFT-K3`의 "유지" 분류를 이 ADR이 번복한다. brief §6.16 K3은 "세 겹 유지, 레일 폐기(ADR-0003)"로 읽는다.
- `design-lint`: 작업 행 CSS에 `border-left`·`border-inline-start` 선언이 있으면 실패(허용 목록 없음). `design-tokens` T13과 무관.
- `design-gallery`: 작업 목록 상태 6종이 forced-colors·다크·라이트에서 axe를 통과하고, 실패 행의 `--danger`·`--danger-ink` 사용 요소가 막대·아이콘·상태 글자 셋뿐인지 DOM에서 센다.
- e2e: `errors.spec.ts`가 레일 색을 보지 않는다(role·text 기반). 영향 없음.

### 재검증 조건

- D62 T4·T5: "다 받은 영상/실패한 영상을 찾아 보세요"(V1과 같은 장면)에서 3명 중 2명 이상이 상태를 구별하지 못하면 레일이 아니라 **아이콘 크기(16 → 20)나 상태 글자 굵기(600)**를 먼저 올린다. 레일 복귀는 그 다음 대안이다.

## 대안과 버린 이유

| 대안 | 버린 이유 |
|---|---|
| 레일 유지, 다른 빨강을 줄여 4겹 → 2겹(B 방식) | 레일은 `--danger` 채움을 `bg` 위에 두는 것이라 다크에서 대비 3.60(통과)이지만 폭 3px의 좁은 면은 g-scale 배율 실측에서 125%에서 흐려진다(brief §6.3). 막대가 이미 같은 색을 더 넓게 보여 준다 |
| 레일을 1px `--separator`로(장식) | 의미가 없는 선을 상태 자리에 두면 "선 하나로 의미를 전하지 않는다"(P4)와 혼동을 부른다 |
| 행 전체 면을 `--danger-soft`로 | 알림(Notice) 면과 작업 행 면이 같은 색이 되어 위계(행 상태 > 인라인)가 사라진다(D37) |
