# 0010 다크 `--danger-ink` 보정

상태: 채택(잠정)   날짜: 2026-10-10   관련: D5, D19, foundations §2.1·§2.2·§2.4·§12-2, ADR-0001

## 맥락

후보 A의 다크 위험 글자색은 `#FD736D`(oklch .72 .17 25)였다. foundations의 불변식 "모든 잉크는 네 바탕(`bg`·`surface`·`surface-2`·`raised`) 전부에서 4.5:1"(WCAG 1.4.3, `E-APPLE-09`·`E-KO-B3`)을 대조하니 `--surface-2`(#3A3A3A) 위에서 4.25:1로 미달했다. 유령 위험 버튼의 hover 면이 `--surface-2`이고(D21), 오류 안내 면 `--danger-soft`(#502824) 위에서도 여유가 작았다.

## 결정

다크 `--danger-ink`를 `#FA8880`(oklch .75 .14 25, ref `--ref-red-75`)로 올린다. 색상각(h 25)은 그대로 두고 명도를 .72 → .75로, 채도를 .17 → .14로 조정했다. 라이트 `--danger-ink`(#BE2323)는 바꾸지 않는다.

| 바탕 | A `#FD736D` | 채택 `#FA8880` |
|---|---|---|
| `--bg` #1F1F1F | 6.19 | 6.98 |
| `--surface` #2B2B2B | 5.32 | 6.00 |
| `--surface-2` #3A3A3A | **4.25** | 4.82 |
| `--raised` #333333 | 4.74 | 5.35 |
| `--danger-soft` #502824 | 4.72 | 5.33 |

## 결과

- foundations §2.2 ref 표(`--ref-red-75`), §2.3 sys 표, §2.4 다크 대비 표, §13 생성물. `design-tokens` DT8이 쌍을 다시 계산한다.
- `--danger-ink`를 쓰는 곳(위험 유령 버튼 글자, ⊗ 아이콘, `aria-invalid` 테두리)은 토큰 이름만 쓰므로 바뀌지 않는다.

### 재검증 조건

- Windows·Linux 실기(README §6-1·§6-2)에서 다크 위험 글자가 탁하거나 튄다는 관찰(D62 `R1` 캡처). 나쁘면 L .74~.76 안에서 조정하고 새 ADR.

## 대안과 버린 이유

| 대안 | 버린 이유 |
|---|---|
| A 값 유지 + 유령 위험 버튼 hover 면을 없앰 | D21(유령 버튼은 hover 있음)과 어긋나고 `--danger-soft` 위 여유도 작다 |
| `--surface-2`를 어둡게 | 다크 네 단계 계단(D9)이 깨지고 다른 쌍이 흔들린다 |
| 채움용 `--danger`와 글자용을 합치기 | 하나로 글자 4.5:1과 흰 글자 4.5:1을 동시에 만족하는 빨강이 없다(foundations §2.1) |
