# 0025 생방송 녹화: 종류 배지 "생방송", 동사 "녹화", 끝내는 버튼 "녹화 마치기"

상태: 채택(잠정)   날짜: 2026-10-16   관련: D10·D42·D43·D63, content.md §4·§15.2, core.md 구현 중 변경 58

## 맥락

사용자 결정(2026-10-16)으로 앱이 진행 중인 생방송을 받는다(방송이 끝나거나 사용자가 마칠 때까지). 지금까지 디자인 시스템은 라이브를 받지 않는 대상으로 두었다: 용어집 "종류(배지)" 행이 `라이브`를 쓰지 않는 말로 정했고(D43), `invalidUrl` 본문이 "라이브 주소는 받을 수 없어요"라고 말했다. 생방송은 VOD·클립과 성질이 다르다: 길이를 모르고(퍼센트·남은 시간이 없다), 사용자가 직접 끝내야 하며, 중간에 끊기면 이어 붙일 수 없다. 그래서 새 단어 둘과 새 동작 하나가 필요하다. 코드는 `crates/core/src/download/live.rs`, 셸 `manager.rs`(`stop_job`, 별도 lane)다.

## 결정

- **종류 배지는 "생방송"**이다(중립 면 + 12px 600 글자, D10 그대로). `라이브`·`실시간`은 쓰지 않는다. "라이브"는 영상 종류 말로 쓰지 않는 규칙을 유지한다(앱 안의 live region 같은 개발 용어는 deck에 없다).
- **영상을 받는 동사 "받다"는 그대로 두고, 진행 중인 방송을 받을 때만 명사 "녹화"를 쓴다**: 상태 줄 "녹화 중 · 1시간 2분 · 3.4GB", 끝내는 버튼 **[녹화 마치기]**, 도중 상태 "녹화를 마치는 중". 시작 버튼은 그대로 [받기]다(한 흐름에서 말이 세 번 바뀌지 않게, D42). 끝나면 일반 완료와 같다("완료", "다운로드를 마쳤어요").
- **일시정지는 생방송에 없다.** `.part`를 남기는 일시정지는 방송 흐름이 끊겨 이어 붙일 수 없다. 생방송 행의 동작은 [녹화 마치기](받은 만큼 최종 파일로 마무리) 하나이고, [취소]는 받은 것까지 버린다(확인 창은 기존 취소와 같고 본문에 "녹화한 부분도 지워요"를 더한다).
- **받다 만 생방송**(앱이 꺼졌거나 끊긴 뒤 `.part`가 남은 것)은 [이어받기]가 아니라 **[저장하기]** 가 맞지만, 새 동사를 더하지 않으려고 기존 [이어받기] 한 버튼으로 두고 본문 줄에서 "받은 부분까지 저장해요"로 설명한다(코어는 이어 붙이지 않고 받은 만큼을 마무리한다). 실사용에서 혼동이 보이면 버튼 말을 바꾼다.
- **게이트는 그대로다**: 생방송도 `live-detail`의 채널 ID로 본인 채널 판정을 한다(관리자 예외 포함). 별도 규칙이 없다.
- **진행 표시**: 막대는 전체 길이를 모르므로 줄무늬 없는 **불확정 막대**를 쓰지 않고 막대를 그리지 않는다(상태 줄 글자만). 놓친 조각이 있으면 상태 줄 끝에 "놓친 조각 {n}"을 더한다.
- 오류 코드 둘을 더한다: `notLive`("지금 방송 중이 아니에요"), `nothingRecorded`("녹화된 내용이 없어요").

## 결과

- 바뀌는 곳: `content.md` §4(종류 행에 "생방송", 새 행 "진행 중인 방송", "라이브"는 계속 금지)·§15.1(`job.*` 키 몇 개)·§15.2(`invalidUrl` 본문, `notLive`, `nothingRecorded`), `design/copy/terms.json`, `app/src/lib/copy/ko.ts`·`errors.ts`, 받기 카드·작업 행·창 닫기 확인.
- gate: `design-copy`(용어집 패리티·쓰지 않는 말), `frontend`(행 표·카드), `e2e-web`.

### 재검증 조건

- 실사용 기록이나 시험에서 [이어받기]가 생방송에서 "이어서 녹화된다"로 읽히면 버튼을 [저장하기]로 바꾸는 새 ADR을 쓴다. 확인: D62 과업에 "방송을 받다 만 파일 처리" 한 과업을 더해 3명 중 2명이 결과를 맞게 말하는지 본다.
- "녹화 마치기"가 "취소"와 헷갈린다는 관찰이 있으면 라벨을 바꾼다. 확인: 첫 실사용 기록.

## 대안과 버린 이유

| 대안 | 버린 이유 |
|---|---|
| 종류 배지를 "라이브"로 한다 | D43이 정한 쓰지 않는 말이다. "생방송"이 뜻이 같고 규칙을 건드리지 않는다 |
| 끝내는 버튼을 [일시정지]로 둔다 | 이어받을 수 있다는 뜻이라 사실과 다르다 |
| 끝내는 버튼을 [정지]·[중지]로 한다 | "정지"는 용어집이 금지한다. "중지"는 같은 뜻의 새 말이라 말이 늘고, 취소와 가깝게 읽힌다 |
| 진행 막대를 불확정(줄무늬)으로 그린다 | 줄무늬는 연결 대기(D40)에 쓴다. 두 상태를 구분할 수 없게 된다 |
| 받다 만 생방송에 [저장하기]를 새로 둔다 | 동사 하나와 상태 분기가 늘고 근거(사용 기록)가 없다. 재검증 조건으로 남긴다 |
