# 0027 받기 전 미리보기: 카드 안 접힌 줄, 자동재생 없음, 실패는 한 Notice

상태: 채택(잠정)   날짜: 2026-10-20   관련: D14·D37·D43·D64, W1·W5, ADR-0009·ADR-0026, `docs/design/features/preview.md` PV14·PV17·P3·P4·P9, app.md 구현 중 변경 110

## 맥락

받기 전에 영상을 확인할 길이 없어, 사용자는 치지직에서 영상을 열어 본 뒤에야 [받기]를 눌렀다. 사용자 결정(2026-10-20)으로 일반 VOD와 클립(통짜 mp4)을 앱 화면의 기본 `<video>`로 미리 본다. Rust가 `watch:` 주소로 중계해 서명 토큰이 프런트로 가지 않는다(preview.md §0). 이 결정은 그 재생 화면을 카드에 어떻게 놓을지다. 디자인 시스템의 세 가지를 건드린다(README §7.1).

- 4번 새 패턴: 카드 안 접힌 미리보기 줄과 `<video>` 화면.
- 5번 [잠정] 항목: 새 상수 `--watch-max-h`. 확인: 아래 재검증 조건의 높이 상한.
- 용어: "미리보기"가 새 말이고, 영상을 여는 말 "재생"은 용어집이 이미 막았다.

## 결정

- **카드 메타 줄과 화질 사이에 `Disclosure variant="inline"` 한 줄 "미리보기"를 둔다. 기본 접힘, 카드마다 새로 시작한다.** 늘 보이되 카드의 흐름(화질 → 폴더 → 이름 → [받기])을 밀지 않는다. 펼칠 때만 `watch_open`을 부른다.
- **자동재생 없음, `preload="metadata"`, 네이티브 `controls`.** 소리와 reduced-motion 문제를 피하고 키보드·접근성은 웹뷰가 맡는다. Esc가 `<video>` 위에서 카드를 닫지 않게 `GlobalShortcuts`가 미디어 요소 대상 Esc를 건너뛴다.
- **줄은 받을 수 있는 통짜 mp4·빠른 다시보기 카드에만 그린다.** `ownership`이 `notOwn`·`unknown`이면 줄 자체가 없다(Disclosure에 비활성 상태가 없다, preview.md P4). 빠른 다시보기(HLS)는 PV-6부터 같은 줄을 둔다(hls.js light, 워커 없음). 생방송에는 없다. `tone`이 아니라 `playbackKind`로 판정한다(클립은 재생 방식과 무관하게 tone이 `clip`이다).
- **실패는 inline Notice 하나**: "미리보기를 열 수 없어요." + [다시 시도] + [치지직에서 보기]. 원인을 가르지 않는다(preview.md Q2: 원인은 로그에 남긴다). 게이트 거부(`notLoggedIn`·`notOwnContent`·`ownershipUnknown`)는 받기와 같은 오류 문구를 쓰고 단추를 두지 않는다. [치지직에서 보기]는 앱이 content에서 정식 주소를 만들어 연다.
- **화면 크기는 카드 열 폭에 16:9, 최대 높이 `--watch-max-h` 360px [잠정].** 새 토큰이라 foundations §1의 속성 자리에 `watch`를 더했다. 확인: 실측(M-PV-1)으로 조이고, 방법은 재검증 조건에 적었다.
- **새 말은 용어집 행 하나**: "미리보기"(쓰지 않는 말 "프리뷰"). "재생"·"재생기"는 "완성 파일 열기" 행의 쓰지 않는 말이 문구 전체(copy deck·`help/*.md`·`patterns.md`·`web.md`)에서 막는다.

### 재검증 조건

- **높이 상한**: `--watch-max-h` 360이 720×520에서 어색하면(펼친 화면이 [받기]를 오래 밀면) M-PV-1 실측 뒤 줄인다.
- **발견성**: 접힌 한 줄을 사용자가 찾는지는 다음 사용자 시험(governance §6)의 카드 장면에서 본다. 못 찾으면 위치(메타 줄 아래)를 다시 정한다.
- **자동재생·전체 화면**: 실물 3 OS 웹뷰에서 Esc·전체 화면 해제가 키 이벤트로 오는지는 M-PV-1에서 본다.

## 대안과 버린 이유

| 대안 | 버린 이유 |
|---|---|
| 카드 위에 늘 펼친 재생기 | 506/520 예산에서 [받기]가 첫 화면 밖으로 밀리고, 대부분의 사용자는 미리 보지 않고 받는다 |
| 별도 대화상자(모달) | 카드의 화질·구간 선택과 영상을 번갈아 보기 어렵다. 포커스 가둠과 Esc 처리가 늘어난다 |
| 허용되지 않은 카드에 비활성 줄 | Disclosure에 비활성 상태가 없고(ui 컴포넌트를 바꿔야 한다), 못 쓰는 줄은 "왜?"만 남긴다. 줄 자체를 두지 않는다 |
