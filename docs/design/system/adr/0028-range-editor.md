# 0028 미리보기 구간 막대: 네이티브 컨트롤 아래 따로 둔 슬라이더 둘, `--p` 예외를 막대로 넓힘

상태: 폐기(→ 0030)   날짜: 2026-10-20   관련: D65, D64, ADR-0027, `docs/design/features/preview-ux.md` PVU1·PVU4·PVU9·PVU15·PVU16, components.md §2.30, foundations §2.4·§2.7, app.md 116

## 맥락

받기 전 미리보기(ADR-0027)로 빠른 다시보기 영상을 앱 안에서 보며 [시작 찍기]·[끝 찍기]로 구간 칸을 채울 수 있다. 사용자 결정(2026-10-20)은 이 구간 고르기를 컷 편집 서비스 수준으로 올리는 것이다. 그 첫 조각으로 영상 아래에 선택 구간을 색으로 칠하고 시작·끝 손잡이를 끌거나 키로 고치는 구간 막대가 필요하다. 디자인 시스템의 세 가지를 건드린다(README §7.1).

- 4번 새 패턴: 카드 안 구간 막대와 멀티 손잡이 슬라이더(앱에 슬라이더 선례가 없다).
- 5번 [잠정] 항목: 손잡이 모양·치수 조합, 재생 위치 선. 확인: 아래 재검증 조건(M-PVU-2 화면 낭독기 실기, 3 OS 갤러리 측정).
- 규칙 예외 확장: 컴포넌트 커스텀 프로퍼티 `--p`(DL7·DS2·DT2)가 진행 막대 하나의 예외였다.

## 결정

- **네이티브 `controls`는 그대로 둔다.** 재생·일시정지·탐색·음량·전체 화면은 웹뷰가 맡고, 구간 막대는 `<video>` 아래에 따로 둔다. ADR-0027 결정 2와 components.md §2.29 규칙 ①은 뒤집지 않고 이 ADR이 덧붙이기만 한다. 자체 재생 막대로 바꾸면 전체 화면·음량·자막·접근성 상태를 모두 직접 책임져야 한다.
- **기능 컴포넌트 `receive/RangeTimeline.svelte`다(`ui/` 아님).** 쓰는 곳이 한 곳이라 governance §5 진입 심사를 넘지 않는다. 손잡이 둘은 `<div role="slider" tabindex="0">`이고 `role="slider"`는 DS1 금지 역할 목록에 없다. 상태의 원천은 구간 칸 두 문자열이며 컴포넌트는 값을 자르지 않고 순수 모델(`rangeEdit.ts`)이 자른다.
- **선택 띠는 `--accent`다(`--accent-soft` 아님).** `--accent-soft`는 트랙 대비가 라이트 1.06·다크 1.35라 1.4.11(3:1)에 못 미친다. `--accent / --track`은 4.28·3.60으로 이미 있는 쌍이다. 재생 위치 `--fg` 선이 띠 위에 놓이므로 `fg / accent` 3.29·3.74를 3:1 쌍으로 contrast.tokens.json과 foundations §2.4에 더한다(DT8).
- **손잡이와 재생 위치는 색만이 아니라 높이와 모양으로 가른다(WCAG 1.4.1).** 재생 위치 선의 높이는 트랙 두께 안뿐이고, 손잡이는 트랙 밖으로 튀어나오는 대괄호(`[` 시작, `]` 끝)다. 손잡이 눌림은 면을 `--accent-pressed`로 채운다(foundations §1 규칙 6). 다크에서 `accent-pressed / surface`는 2.29라 눌린 순간 튀어나온 부분의 대비가 3:1 아래이지만, 포인터를 쥔 동안만의 일시 상태이고 위치는 턱 모양·테두리로 남으므로 참고값 행으로만 적는다.
- **누름 영역은 앵커에서 바깥쪽으로만 편다**(시작은 왼쪽, 끝은 오른쪽, 폭 `--hit-min`). 간격 1초로 붙은 손잡이도 겹치지 않는다. 막대 누름은 영상 탐색만 하고 손잡이 값은 바꾸지 않으며 포커스를 코드로 옮기지 않는다.
- **`--p` 예외를 구간 막대로 넓힌다.** 위치는 손잡이 앵커·선택 띠 두 겹·재생 위치가 각자 가진 `style:--p`(0~1) 디렉티브 하나뿐이고 새 커스텀 속성 이름·새 `style:` 디렉티브는 없다. 정지 상태 `transform`·`translate(-50%)`는 쓰지 않고 너비 0 앵커 안 flex로 가운데를 맞춘다(DL11). 새 토큰은 없다: `--progress-h`·`--hit-min`·`--control-h-sm`·`--space-4`의 조합이다(PVU16).
- **순서가 뒤집힌 동안(`band = false`)에는 띠를 그리지 않고** 두 손잡이의 슬라이더 경계는 모두 `[0, floor(길이)]`다. 움직인 손잡이를 다른 손잡이로 자르지 않아 한 걸음에 튀지 않고, `aria-valuenow`가 늘 `[valuemin, valuemax]` 안이다.

### 재검증 조건

- **화면 낭독기**: VoiceOver·NVDA·Orca에서 "시작 시각, 1분 5초, 슬라이더"처럼 읽히고 ←/→로 값이 바뀌는지 본다(M-PVU-2). 불안정하면 손잡이를 `<input type="range">` 둘로 바꾸는 안을 다시 연다.
- **손잡이 모양·치수**: 대괄호 턱과 24/40 높이가 3 OS 웹뷰에서 읽히는지, 붙은 손잡이(1초 간격)를 끌 수 있는지 갤러리 측정으로 본다. 안 되면 `--range-*` 접두 토큰을 세 곳(foundations §1 표, `check-tokens.mjs`의 치수 속성 목록, `spec-check.mjs` 접두)에 더하고 이 ADR에 적는다.
- **긴 영상**: 수 시간짜리에서 끌기 정밀도가 낮다. 막대 확대(zoom)는 1단계 범위 밖이고, 정밀은 ±1초·키·시각 칸이 맡는다.

## 대안과 버린 이유

| 대안 | 버린 이유 |
|---|---|
| 자체 재생 막대로 네이티브 컨트롤 대체 | 전체 화면·음량·자막·접근성 상태를 모두 직접 책임져야 한다(ADR-0027 결정 2를 뒤집음) |
| `<input type="range">` 둘 겹치기 | 한 막대 위에 두 손잡이의 서로 제한·띠 칠하기·붙은 손잡이의 누름 영역을 제어하기 어렵고 브라우저마다 모양이 다르다. 실기(M-PVU-2)에서 슬라이더 역할이 불안정하면 다시 연다 |
| 선택 띠를 `--accent-soft`로 | 트랙 대비 라이트 1.06·다크 1.35로 1.4.11(3:1)에 못 미친다 |
| 새 `--range-*` 토큰 | 기존 `--progress-h`·`--hit-min`·`--control-h-sm`·`--space-4` 조합으로 되므로 만들지 않는다(PVU16). 안 되는 치수가 나오면 그때 더한다 |
