# 네이버 로그인 정보 넣기

연령 제한이나 구독자 전용 영상은 네이버에 로그인한 상태여야 받을 수 있어요. 브라우저에서 값 두 개를 복사해 앱에 넣어 주세요.

1. 브라우저에서 chzzk.naver.com에 로그인해 주세요.
2. 개발자 도구를 열어 주세요.
3. ‘Application’ › ‘쿠키’에서 https://chzzk.naver.com 항목을 열어 주세요.
4. NID_AUT와 NID_SES의 값을 각각 복사해 주세요.
5. 앱의 설정 › 네이버 로그인 정보에 두 값을 각각 넣어 주세요.

개발자나 관리자는 이 값을 묻지 않아요. 보내 달라는 메시지를 받으면 사기예요.

앱에서 [문제 보고용 정보 복사]를 누른 뒤 관리자에게 보내 주세요. 복사한 내용에는 채널 이름이나 로그인 정보가 들어가지 않아요. 관리자는 쿠키나 비밀번호를 절대 묻지 않아요.
