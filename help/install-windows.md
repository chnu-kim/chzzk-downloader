# Windows에서 PC 보호 창이 뜰 때

설치 파일을 처음 열면 Windows가 ‘PC 보호’ 창을 보여 줄 수 있어요. 앱이 문제라는 뜻이 아니라, 아직 알려지지 않은 프로그램이라 한 번 물어보는 거예요.

1. ‘PC 보호’ 창에서 ‘추가 정보’를 눌러 주세요.
2. 나타난 ‘실행’을 눌러 주세요.

스마트 앱 컨트롤이 켜져 있으면 설치할 수 없어요. 끄면 다시 켤 수 없으니 관리자에게 먼저 물어 주세요.

앱에서 [문제 보고용 정보 복사]를 누른 뒤 관리자에게 보내 주세요. 복사한 내용에는 채널 이름이나 로그인 정보가 들어가지 않아요. 관리자는 쿠키나 비밀번호를 절대 묻지 않아요.
