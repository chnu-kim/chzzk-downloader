# 브라우저가 열리지 않을 때

치지직 로그인은 기본 브라우저에서 진행해요. 로그인 창이 뜨지 않으면 아래 순서대로 해 주세요.

1. 앱의 로그인 화면에서 [브라우저 다시 열기]를 눌러 주세요.
2. 그래도 열리지 않으면 [로그인 주소 복사]를 눌러 주세요.
3. 브라우저를 직접 열고 주소창에 복사한 주소를 붙여넣어 주세요.
4. 치지직 로그인을 마치면 앱으로 돌아가 주세요.

앱에서 [문제 보고용 정보 복사]를 누른 뒤 관리자에게 보내 주세요. 복사한 내용에는 채널 이름이나 로그인 정보가 들어가지 않아요. 관리자는 쿠키나 비밀번호를 절대 묻지 않아요.
