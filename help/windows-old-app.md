# Windows에서 업데이트한 뒤 옛 앱이 남아 있을 때

앱 이름이 ‘치지직 다운로더’에서 ‘VOD 클립 다운로더’로 바뀌었어요. Windows는 이름이 바뀌면 업데이트가 옛 앱을 덮어쓰지 않고 새 앱을 따로 설치해요. 그래서 시작 메뉴에 두 앱이 보일 수 있어요. 설정과 로그인은 그대로 이어져요.

1. ‘VOD 클립 다운로더’를 열어 잘 열리는지 확인해 주세요.
2. Windows 설정 › 앱 › 설치된 앱에서 ‘치지직 다운로더’를 찾아 지워 주세요.

옛 앱은 더 이상 업데이트되지 않으니 지우는 것이 좋아요. 지울 때 앱 데이터까지 지우는 선택 항목이 보이면 켜지 마세요. 새 앱이 같은 데이터를 써요.

앱에서 [문제 보고용 정보 복사]를 누른 뒤 관리자에게 보내 주세요. 복사한 내용에는 채널 이름이나 로그인 정보가 들어가지 않아요. 관리자는 쿠키나 비밀번호를 절대 묻지 않아요.
